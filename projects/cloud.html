Project 1: Cloud Fundamentals

Timeline

August 2025 – Ongoing

What this is

This section documents my hands on learning with cloud fundamentals, starting from AWS Free Tier in August 2025. Rather than just reading theory, I focused on practical setup and understanding how cloud infrastructure works.

What I actually did

  • Created and configured an AWS account with Free Tier
  • Launched an EC2 instance (Linux server) on AWS
  • Installed and configured NGINX as a web server
  • Made a website publicly accessible over the internet
  • Used Git Bash to push changes directly to the live server
  • Understood the difference between public and private access
  • Learned IAM basics: root user vs IAM users and why root should be protected
  • Practiced setting permissions and access control on AWS resources

Concepts I understand

  • Cloud is not magic, it is someone else's computers rented on demand
  • IaaS vs PaaS vs SaaS and when each is used
  • Why companies move to cloud: cost, scalability, availability
  • Public vs private access and why it matters for security
  • IAM: why you never use root for daily tasks
  • How a request travels from browser to server and back
  • What ports are and why 80 and 443 matter
  • What a firewall does at a conceptual level

Tools used

  • AWS (EC2, IAM, S3 basics)
  • Linux command line
  • NGINX
  • Git and Git Bash

What I would improve

I want to rebuild this setup properly with HTTPS, a real domain, and documented architecture. That is planned as a future update to this section.

Honest reflection

My AWS Free Tier expired before I could document everything properly. But the hands-on experience gave me a clear mental model of how cloud infrastructure works, which directly supported all the IT projects I built later.
