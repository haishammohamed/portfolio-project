My IT Journey

Early interest

I started exploring technology early. When I was around 13, I built simple websites using tools like Wix. That experience taught me how structure, design, and user flow work together.

Why I did not study IT earlier

Due to life circumstances and practical responsibilities, I followed a different study path (Business Administration). However, my interest in IT stayed consistent in the background.

Why I am focusing on IT now

Living in Germany and preparing for professional stability helped me plan long-term. I am now preparing step by step for an IT Ausbildung starting in 2026.

What I have already practiced

  • AWS basics: I launched a simple web server and made a small website publicly accessible.
  • Web server setup: I used NGINX to serve a website.
  • Version control: I used Git (via Git Bash) to update files and push changes.
  • Understanding workflow: I understand how a main branch is commonly used for the live version of a project.

What I am improving next

  • Stronger fundamentals: networking, servers, storage, virtualization, and cloud concepts.
  • More practice with structured documentation and simple project write-ups.
  • Basic logic skills (simple scripting / simple database concepts) to support application development learning.

My focus

I am interested in business-oriented IT (ERP/CRM environments), reliable IT fundamentals, and practical learning through small projects. Cloud is a part of my learning journey, but my main goal is to build a solid base for an IT Ausbildung.
